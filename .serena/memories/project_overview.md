# プロジェクト概要

## プロジェクト名
XiaoZhi AI Chatbot (xiaozhi-esp32)

## 目的
ESP32ベースの音声インタラクション機能を持つAIチャットボット。音声対話のエントリーポイントとして、Qwen/DeepSeekなどの大規模言語モデルのAI機能を活用し、MCPプロトコル経由でマルチターミナル制御を実現する。

## 主な特徴
- オフライン音声ウェイクアップ（ESP-SR使用）
- ストリーミングASR + LLM + TTSアーキテクチャによる音声対話
- WebsocketまたはMQTT+UDP通信プロトコル対応
- 話者認識（3D Speaker）
- OLED/LCD表示、絵文字表示対応
- バッテリー表示と電源管理
- 多言語サポート（中国語、英語、日本語など）
- ESP32-C3、ESP32-S3、ESP32-P4チッププラットフォーム対応
- デバイス側MCPによるデバイス制御（スピーカー、LED、サーボ、GPIOなど）
- クラウド側MCPによる大規模モデル機能の拡張（スマートホーム制御、PC操作、知識検索など）

## 対応ハードウェア
70種類以上のオープンソースハードウェアに対応。各ボードの設定は`main/boards/`ディレクトリに格納。

## バージョン
現在のバージョン: 2.1.0（v2ブランチ）
v1からv2への移行時はパーティションテーブルが互換性がないため、OTAアップグレードは不可。手動フラッシュが必要。
